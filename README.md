## What is vairee?

vairee is a recruiting platform that:

1. **Preserves talent privacy** — Talents are represented by Digital Identities (anonymous IDs) until a hiring manager commits to a candidate
2. **Uses evidence-based evaluation** — Every claim in screening reports is backed by structured data from AI conversations, not guesswork
3. **Puts humans in the loop** — When the system encounters missing or uncertain data, it pauses and asks for human input before continuing
4. **Enables fair comparison** — Hiring managers see anonymized "Blind CV" style profiles first, reducing bias
