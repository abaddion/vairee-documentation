## What is vairee?

vairee serves **anyone with a professional life**—not only hiring managers. It connects:

- **Hiring managers** with candidates
- **Professionals** with companies, projects, and opportunities
- **Service providers** with clients
- **Clients** with service providers

vairee is a digital identity platform that:

1. **Preserves privacy** — Entities are represented by Digital Identities (anonymous IDs); data is revealed only when both parties digitally handshake
2. **Does not decide nor reject** — vairee runs real conversation based on data (not keywords); AI is a helper; users receive data-supported information and recommendations and make informed decisions; a profile can never be rejected and always has a voice
3. **Uses evidence-based evaluation** — Every claim is backed by structured data from AI-powered conversations; fit is evaluated in both directions
4. **Preselects lightly** — Minimum-data filtering creates a huge potential pool; missing data → request clarification, not exclusion; hold before recommending when critical data (e.g. location) is missing
5. **Puts users in the loop** — Missing details are clarified with the users (not by AI that assumes or hallucinates) whose profiles are incomplete; profiles are living organisms, never 100% complete, shaped by interactions
6. **Profile transparency** — Users can review everything (how many conversations included/excluded, why); provide their own opinion (evaluated if valid); cannot force-evaluate for mismatched roles; can create a new vairee-card for a different goal
7. **Multiple vairee-cards** — One user can have several vairee-cards, each for a specific professional goal (unlike LinkedIn’s single profile); no loss of credibility across different paths
8. **Enables fair comparison** — Anonymized "Blind CV" and "Blind jobs" style profiles reduce bias
